## 🔧 Setup Instructions

### Step 1: Set Your Domain

1. Create a `.env.local` file in the root directory:
```bash
NEXT_PUBLIC_SITE_URL=https://yourdomain.com
```

**Replace `yourdomain.com` with your actual domain** (e.g., `anas-enaqadi.dev`, `www.anas-enaqadi.com`)

### Step 2: Update robots.txt

Edit `public/robots.txt` and replace `https://yourdomain.com` with your actual domain.

### Step 3: Verify Your Site

#### Google Search Console
1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add your property (your domain)
3. Verify ownership (HTML tag method recommended)
4. Add the verification meta tag to your layout if needed
5. Submit your sitemap: `https://yourdomain.com/sitemap.xml`

#### Bing Webmaster Tools
1. Go to [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. Add your site
3. Verify ownership
4. Submit your sitemap
